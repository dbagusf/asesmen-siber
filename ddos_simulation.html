Bagaimana Botnet Dibangun?

Botnet adalah jaringan komputer yang terinfeksi malware dan dikendalikan diam-diam oleh attacker (disebut botmaster). Komputer yang terinfeksi disebut zombie atau bot. Berikut tahapan lengkap bagaimana botnet dibangun:

1
🎣 Penyebaran Malware (Initial Infection)

Attacker menyebarkan malware melalui berbagai vektor serangan untuk menginfeksi komputer korban:

📧
Phishing Email
Email palsu berisi lampiran berbahaya (.exe, .docm) atau link ke halaman tiruan yang mendownload malware secara otomatis.
🌐
Drive-by Download
Situs web berbahaya yang mengeksploitasi kerentanan browser (unpatched Flash, Java, PDF reader) untuk install malware tanpa klik pengguna.
💾
Infected Software / Crack
Software bajakan, game crack, atau keygen yang dibundel dengan trojan. Pengguna menginstal sendiri tanpa sadar.
🔌
USB / Removable Media
Flashdisk yang terinfeksi menyebar via autorun atau file menyamar sebagai folder biasa. Sangat efektif di lingkungan kantor.
🔓
Exploit Kerentanan RCE
Memanfaatkan celah keamanan di layanan yang terekspos internet (SMB, RDP, IoT firmware) untuk eksekusi kode dari jarak jauh.
📱
Fake App / APK
Aplikasi palsu di luar Play Store atau sideloaded APK yang meminta permission berlebihan untuk akses penuh ke perangkat.
2
🪱 Instalasi & Persistensi (Rootkit/Trojan)

Setelah berhasil masuk, malware melakukan serangkaian tindakan untuk bertahan di sistem:

Registry Persistence
HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
Otomatis dijalankan setiap Windows startup.
Scheduled Task
Membuat task terjadwal yang eksekusi tiap jam, tersembunyi dari Task Manager biasa.
Kernel Rootkit
Bersembunyi di level kernel OS, tidak terlihat di file explorer atau antivirus biasa.
3
📡 Koneksi ke C&C Server (Command & Control)

Bot yang terinfeksi "menelepon ke rumah" — menghubungi server C&C milik attacker untuk menerima instruksi:

IRC / HTTP Botnet
Generasi lama. Bot join channel IRC rahasia dan menunggu perintah. Mudah diblokir jika C&C diketahui.
P2P Botnet
Tidak ada server pusat. Bot berkomunikasi peer-to-peer sehingga sangat sulit di-takedown oleh pihak berwenang.
Domain Generation Algorithm (DGA)
Bot menghasilkan ribuan domain acak per hari. Attacker hanya perlu mendaftarkan satu — sangat sulit diblokir.
Fast-Flux DNS
IP server C&C berubah setiap beberapa menit menggunakan DNS TTL sangat pendek — menyulitkan pelacakan.
4
🤖 Bot Siap Dikendalikan (Zombie Mode)

Komputer korban kini menjadi zombie — berjalan normal dari sisi pengguna, namun diam-diam menjalankan perintah attacker:

→ Bot melaporkan spesifikasi (bandwidth, CPU, OS) ke botmaster
→ Botmaster mengklasifikasi bot berdasarkan kemampuan
→ Bot dapat menerima update malware baru kapan saja
→ Pengguna tidak menyadari — komputer terasa sedikit lemot saja
→ Bot juga bisa mencuri password, data kartu kredit, dll.
5
💥 Eksekusi Serangan DDoS

Saat botmaster memberikan perintah serangan, semua bot secara bersamaan membanjiri target:

→ Botmaster kirim perintah: ATTACK 203.0.113.5 HTTP 80 3600
→ Ribuan bot mulai mengirim jutaan request per detik ke target
→ IP sumber dipalsukan (spoofed) agar sulit dilacak
→ Server target kehabisan resource dan tidak bisa melayani user sah
→ Layanan down — website tidak bisa diakses
Arsitektur Botnet — Command & Control
LAYER 3-4
Volumetric Attack
UDP Flood
Mengirim paket UDP dalam jumlah masif ke port acak. Target terpaksa memproses setiap paket dan membalas ICMP "Destination Unreachable" — menghabiskan bandwidth dua arah.
Ukuran tipikal: 100 Gbps — 2+ Tbps
ICMP Flood (Ping Flood)
Membanjiri target dengan paket ICMP Echo Request. Memaksa target terus merespon ping hingga bandwidth habis.
DNS Amplification
Mengirim query DNS kecil dengan IP sumber dipalsukan (IP target). Server DNS membalas respons besar langsung ke target. Amplifikasi hingga 70x lipat dari ukuran asli.
Contoh: kirim 100B → target terima 7.000B
NTP Amplification
Exploit perintah monlist NTP yang mengembalikan daftar 600 IP terakhir. Amplifikasi hingga 556x.
LAYER 4
Protocol Attack
SYN Flood
Mengeksploitasi TCP three-way handshake. Attacker mengirim ribuan SYN dengan IP palsu. Server mengalokasikan resource menunggu ACK yang tidak pernah datang — tabel koneksi penuh.
CLIENT→SYN→SERVER→SYN-ACK→[CLIENT HILANG] ×∞
Ping of Death
Mengirim paket ICMP melebihi ukuran maksimum (65.535 bytes). Saat di-reassemble, buffer overflow menyebabkan crash atau freeze.
Smurf Attack
Mengirim ICMP broadcast ke seluruh jaringan dengan IP sumber = IP target. Semua host membalas ke target sekaligus.
Fragmentation Attack
Mengirim paket terfragmentasi yang tidak bisa di-reassemble. Menghabiskan memori buffer reassembly target.
LAYER 7
Application Attack
HTTP Flood
Mengirim jutaan request HTTP GET/POST yang tampak sah. Memaksa server memproses logic aplikasi penuh. Lebih sulit dibedakan dari trafik normal.
Slowloris
Membuka banyak koneksi HTTP dan mengirim header secara sangat lambat — tidak pernah selesai. Setiap koneksi tetap terbuka, menghabiskan pool koneksi server.
Butuh bandwidth kecil tapi efek besar pada Apache/IIS
SSL Exhaustion
Berulang kali memulai SSL handshake. Operasi kriptografi sangat CPU-intensive — bahkan beberapa ratus koneksi/detik bisa melumpuhkan server.
ADVANCED
Multi-Vector Attack
Multi-Vector DDoS
Menggabungkan beberapa jenis serangan secara bersamaan — volumetric + protocol + application layer. Sangat sulit dimitigasi karena membutuhkan respons di semua layer sekaligus.
Carpet Bombing
Menyerang seluruh subnet IP (/24) sekaligus, bukan satu target. Semua host dalam range IP terkena — efektif mematikan seluruh layanan ISP.
Ransom DDoS (RDoS)
Attacker mengirim peringatan: bayar tebusan atau diserang DDoS. Sering disertai serangan demonstrasi kecil sebagai "bukti kemampuan".
Pelaku: Fancy Bear, Lazarus Group, dll.
🛡️ Pertahanan Sisi Server
✓
Rate Limiting & Throttling — Batasi jumlah request per IP/detik. Blokir otomatis IP yang melampaui threshold.
✓
SYN Cookies — Teknik TCP yang tidak mengalokasikan resource sampai handshake benar-benar selesai. Melindungi dari SYN flood.
✓
Blackhole Routing (RTBH) — Membuang semua trafik ke IP yang diserang. Melindungi infrastruktur lain tapi target tetap down.
✓
Anycast Diffusion — Menyebarkan trafik ke banyak server global. Serangan "diencerkan" ke banyak titik.
✓
Web Application Firewall (WAF) — Filter trafik Layer 7, blokir pattern serangan yang dikenal.
☁️ Cloud & CDN Protection
✓
Cloudflare / Akamai DDoS Scrubbing — Trafik melewati scrubbing center yang memfilter serangan sebelum sampai ke server asli.
✓
BGP Flowspec — Propagasi aturan filtering ke seluruh router upstream ISP. Membuang trafik buruk di sumber.
✓
Over-Provisioning Bandwidth — Menyiapkan kapasitas jauh melebihi kebutuhan normal sehingga flood tidak langsung meluap.
✓
ML-based Anomaly Detection — AI mendeteksi pola trafik anomali secara real-time dan memblokir otomatis sebelum impact.
🖥️ Lindungi Komputer Anda dari Botnet
✓
Update OS dan software secara rutin — patch kerentanan sebelum dieksploitasi
✓
Gunakan antivirus/EDR yang terpercaya dan selalu update signature-nya
✓
Jangan download software dari sumber tidak resmi — hindari crack & keygen
✓
Waspadai email phishing — verifikasi pengirim sebelum klik link atau buka lampiran
✓
Aktifkan firewall dan monitor aktivitas jaringan yang mencurigakan
✓
Gunakan DNS-over-HTTPS untuk mencegah DNS hijacking oleh C&C server
✓
Monitor penggunaan CPU/bandwidth yang tidak wajar — bisa tanda infeksi bot
⚖️ Aspek Hukum
🇮🇩 Indonesia — UU ITE
Serangan DDoS termasuk pelanggaran UU No. 11 Tahun 2008 tentang ITE (direvisi 2024) Pasal 32-33. Ancaman pidana penjara hingga 8 tahun dan/atau denda hingga Rp 2 miliar.
🌍 Internasional
Di AS, serangan DDoS melanggar Computer Fraud and Abuse Act (CFAA) — hukuman hingga 10+ tahun penjara. Di Uni Eropa: Directive on Attacks Against Information Systems.
⚠️ Peringatan Penting
Simulasi ini hanya untuk tujuan edukasi dan pemahaman keamanan siber. Melakukan serangan DDoS terhadap sistem nyata adalah TINDAK PIDANA yang dapat berujung penjara dan denda besar.
