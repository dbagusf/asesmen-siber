📚 Cara Kerja Serangan MITM
1️⃣
ARP Poisoning
Attacker mengirim paket ARP palsu sehingga trafik jaringan diarahkan melalui komputer attacker sebelum ke tujuan.
2️⃣
Packet Interception
Semua data yang dikirim Alice melewati attacker. Attacker membaca, memodifikasi, atau memblokir pesan sesuka hati.
3️⃣
Session Hijacking
Attacker dapat mengambil alih sesi login, mencuri cookie, atau memalsukan identitas salah satu pihak yang berkomunikasi.
🛡️ Cara Pencegahan
✅ Gunakan HTTPS / TLS untuk enkripsi end-to-end
✅ Aktifkan HSTS di server web
✅ Gunakan VPN di jaringan publik / tidak dipercaya
✅ Verifikasi sertifikat SSL secara berkala
✅ Aktifkan Dynamic ARP Inspection di switch jaringan
✅ Gunakan autentikasi multi-faktor (MFA)
