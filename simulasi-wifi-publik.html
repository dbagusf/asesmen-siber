☠️ Kredensial Tertangkap

🕵️
KRITIS

Man-in-the-Middle (MITM)

Penyerang memposisikan diri di antara Anda dan router, membaca semua komunikasi tanpa terdeteksi.

Target: Semua pengguna WiFi publik

Tools: arpspoof, Ettercap, Bettercap

Risiko: Pencurian data sensitif lengkap

🎣
KRITIS

Packet Sniffing

Monitoring semua paket data yang melintas di jaringan. Data HTTP (tanpa enkripsi) terbaca sepenuhnya.

Target: Pengguna situs HTTP

Tools: Wireshark, tcpdump, dsniff

Risiko: Login & password dicuri

😈
KRITIS

Evil Twin AP

Access point palsu dengan SSID identik. Korban terhubung tanpa sadar karena sinyal lebih kuat.

Target: Pengguna yang auto-connect

Tools: hostapd-wpe, airbase-ng

Risiko: Kontrol penuh lalu lintas

🌐
TINGGI

DNS Spoofing

Pemalsuan respons DNS untuk mengarahkan korban ke situs web palsu meskipun mengetikkan URL yang benar.

Target: Semua pengguna

Tools: dnsspoof, Metasploit

Risiko: Phishing + malware

🍪
TINGGI

Session Hijacking

Mencuri cookie sesi aktif untuk mengambil alih akun yang sudah login tanpa memerlukan password.

Target: Sesi yang aktif (browser)

Tools: Firesheep, Hamster+Ferret

Risiko: Akun sosmed diambil alih

💥
SEDANG

SSL Stripping

Menurunkan koneksi HTTPS menjadi HTTP, sehingga enkripsi hilang dan data dapat dibaca penyerang.

Target: Situs HTTPS tanpa HSTS

Tools: sslstrip, Bettercap

Risiko: Data terenkripsi jadi plaintext

🛡️ Cara Melindungi Diri

🔐

Gunakan VPN

VPN mengenkripsi seluruh lalu lintas internet Anda. Bahkan jika penyerang mencegat, data terlihat acak dan tidak terbaca. Perlindungan terbaik di WiFi publik.

95% efektif
🔒

Hanya Gunakan HTTPS

Pastikan URL selalu diawali https:// dan ikon gembok terkunci. Gunakan ekstensi "HTTPS Everywhere" di browser.

75% efektif
📱

Nonaktifkan Auto-Connect WiFi

Matikan fitur terhubung otomatis ke jaringan yang pernah digunakan. Ini mencegah Evil Twin AP menangkap perangkat Anda.

80% efektif
🔑

Aktifkan Two-Factor Authentication

Meski password dicuri, penyerang tetap tidak bisa masuk tanpa kode OTP kedua. 2FA wajib untuk email, perbankan, dan media sosial.

90% efektif
🚫

Hindari Transaksi Sensitif

Jangan lakukan internet banking, belanja online, atau login akun penting saat menggunakan WiFi publik tanpa VPN.

100% efektif
